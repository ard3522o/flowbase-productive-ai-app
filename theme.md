# Nestwork UI theme

## Direction

Fresh, bright, and quietly optimistic. Use crisp blue-white surfaces, light slate structure, and violet as the primary action color. Colorful icon chips add personality without making the interface noisy.

## Palette

- Canvas: `#F8FAFF`; surfaces: `#FFFFFF`; borders: `#E2E8F0`
- Primary: violet `#7C3AED` / indigo `#4F46E5`
- Supporting icon tones: sky, emerald, amber, rose, orange, fuchsia, and slate at the `100` background / `600` foreground Tailwind scale.
- Main text: `#0F172A`; secondary text: `#64748B`; quiet text: `#94A3B8`.

## Type and spacing

- Use 10px uppercase group labels, 12–13px interface text, 15px section titles, and 30–36px page titles.
- Prefer 8px spacing increments. Sidebar menu items use 6px internal padding; cards use 16–20px.
- Corners are friendly, not bubbly: 10–12px for controls and 16px for cards.

## Components

- Sidebar navigation is compact, grouped, and icon-led. Active items use a pale violet surface, while every icon sits in a colored 24px chip.
- Keep shadows low and diffuse; use borders to define most surfaces.
- Use violet only for key actions and current state. Supporting colors identify a tool or content type, not priority.
